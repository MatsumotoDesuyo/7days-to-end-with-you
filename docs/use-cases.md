# ユースケースと「正常」の定義（草案）

この文書はテスト整備の逆算元となる「このアプリがどういうものか」の定義である。
運用面の契約は [DEPLOYMENT.md](../DEPLOYMENT.md)（platform 管理・編集禁止）を、
ゲーム自体の詳細（出典つき）は [game-overview.md](game-overview.md) を参照。

## 1. このアプリは何か

『7 Days to End with You』の暗号解読補助ツール。

ゲーム内言語の実態は「英語 → シーザー暗号（変則あり）→ アルファベットを独自記号に置換」した弱い暗号である。暗号の元が英語であるため、英語圏プレイヤーは語長（dog は必ず 3 文字）など言外の情報を無意識に得られるが、日本語プレイヤーは得られない。**このツールは、その日英プレイヤー間の情報格差を埋める**。

設計思想として、答えの一括提示はしない。ゲーム本来の「読み解く楽しみ」を壊さないため、**「シーザー暗号ならこの単語の可能性がある」という候補の提示に留める**。機能の追加・変更はこの節度を守ること。

## 2. 前提となるゲームの暗号仕様

- シーザーシフトは通常の mod 26 ではなく、**Z をスキップする 25 文字周期（Y の次が A）**。攻略記事複数で裏どり済み。
- **シフト量は単語ごとに異なる**（同じ単語内では一貫）。暗号文からシフト量を直接求める確実な方法はないため、復号は全シフトの総当たりになる。
- 25 文字周期の帰結として、**ずらし量 0 と 25 の候補文字列は同一**になる（Z を含まない入力の場合）。
- ゲーム内の単語に Z は使われない。ただし **Z に対応する記号は「A の代替」として出現し得る**ため、Z の入力は起こり得る。
- 一部の単語は省略形で記載される（→ 本ツールのスコープ外、§5）。
- ゲームに登場する単語は最大 12 文字程度。

## 3. ユースケース

アクターは全 UC 共通で「ゲームをプレイ中の（主に日本語圏の）プレイヤー」。

### UC1: ゲーム内記号をボタンで入力して候補を見る（主系）

1. ゲーム画面の単語を見ながら、対応する記号画像つきボタン（A〜Z + BackSpace）で文字を入力する。
2. 入力のたびに、全 26 シフト分の候補文字列リストが表示される。
3. プレイヤーはゲーム内の文脈と突き合わせ、自力で単語を推測する。

### UC2: キーボードで直接タイプして候補を見る（重要機能）

1. テキスト欄に英字を直接タイプ（またはペースト）する。
2. 入力は英字のみ抽出・大文字化され、UC1 と同じ候補リストが表示される。

### UC3: 辞書検索で意味つきの候補に絞る

1. UC1/UC2 の入力状態で「辞書検索」ボタンを押す。
2. 全 26 シフト候補のうち、簡易英和辞書（ejdict）に存在する単語だけが**意味つきで、シフト候補リストより上に**表示される。
3. 0 件のときは「見つかりませんでした」と表示される。

### UC4: 入力の修正

1. BackSpace ボタンで末尾 1 文字を削除できる。テキスト欄での編集も UC2 と同様に反映される。

## 4. 「正常」の定義（テストケースの逆算元）

| # | 観点 | 定義 | 状態 |
|---|------|------|------|
| N1 | シフト変換 | Z スキップの 25 文字周期（'Y'+1 → 'A'）。mod 26 に「直す」のは誤り | 確定 |
| N2 | Z 入力 | 入力が Z の文字だけ mod 26 で変換される現行分岐を**仕様として固定**（製作時に手動検証済み） | 確定 |
| N3 | 候補表示 | 全 26 シフト分を常に表示（シフト量は単語ごとに異なり最大 26 まであり得るため、総当たり提示が必須） | 確定 |
| N4 | 辞書ヒット表示 | シフト候補リストより**上**に表示されること。並び順そのものに意味はない | 確定 |
| N5 | 辞書ヒット件数 | 上限 100 件。重要度順は辞書の制約上不可能なので現状維持（100 件ヒットは実際上起きない） | 確定 |
| N6 | 省略形の単語 | ヒットしなくて**正常**（スコープ外） | 確定 |
| N7 | 直接入力の正規化 | 英字のみ抽出・大文字化。現行実装は**先頭から連続する英字のみ**を採用（例: `abc1def` → `ABC`、先頭が非英字なら空になる）。なお先頭スペースは `type="email"` の入力仕様によりブラウザ側で刈り取られ、正規化ロジックには届かない | 確定（現状固定。改善案は issue #4） |
| N8 | 空入力・異常入力 | 空文字で辞書検索した場合は空応答。サーバーは落ちず、**必ず応答を返す**（SQL エラー時は 500 + 空配列） | 確定（#3 で強化済み） |
| N9 | 辞書 | ejdict（同梱 SQLite、読み取り専用）。辞書にない単語が出ないのは正常 | 確定 |

## 5. スコープ外

- 省略形で記載される単語の解読
- 答え（対応表・全訳）の一括提示 — 設計思想（§1）に反する
- マーケティング的な機能（流行期は過ぎており、潜在ユーザーも少ない）

## 6. 継続運用の「正常」

- **push すると CI でテストが回り正常性が担保され、GHCR のイメージが自動更新される（CI 緑）**。ここまでがアプリ側の責務。
- それ以降（pull・起動・proxy 等）は platform 側の責務でスコープ外（DEPLOYMENT.md の契約どおり）。
- バックアップ作成・ログ出力の方式は platform 側で共通サービスが指定される見込みのため**保留**。論点としては把握しておく。

## 7. 未確定・要確認

- Z 分岐（N2）の厳密な意味論（「Z を A と同一視」との異同）。現行固定と決定済みだが、将来変更するなら別 issue。
